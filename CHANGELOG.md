## [0.1.0] — 2026-07-07

Первый публичный релиз: полиморфные контент-блоки для Laravel 12 с админкой на MoonShine 4.

### Добавлено

- **Полиморфное подключение блоков.** Упорядоченные, переключаемые и хранящиеся в JSON блоки цепляются к любой Eloquent-модели через morph-связь `blockable` (страницы, товары, категории — что угодно) с помощью трейта `HasContentBlocks` и контракта `HasContentBlocksContract`.
- **Два типа блоков.** *Статические* — данные берутся из сохранённого JSON-контента; *динамические* — данные вычисляются в момент рендера через внедряемые в конструктор зависимости (списки товаров, коллекции, фиды).
- **Рендерер блоков.** `BlockRenderer::render($model, $request)` отдаёт структурированный payload: неактивные блоки пропускаются, порядок соответствует drag & drop, каждый блок оформлен как конверт `{ id, code, name, data }`. Строки с незарегистрированным типом пропускаются с событием `UnknownBlockTypeEncountered`.
- **Реестр блоков.** Разрешение блоков через контейнер (`BlockRegistryInterface`), без фасадов и глобального состояния; метод `override()` для замены упакованного или прикладного блока (случайные коллизии кодов бросают исключение).
- **Админка MoonShine 4.** Ресурс с пер-типовыми полями формы, drag & drop сортировкой и инлайновым переключением активности (на базе [ewk/moonshine-resource-kit](https://github.com/einzelwerk/moonshine-resource-kit)), а также встраиваемое поле `ContentBlocksField` для формы любого ресурса — возвращает обычный `HasMany`, поэтому все его опции остаются доступны.
- **Валидация контента блока.** Метод `rules()` с ключами относительно контента блока — пакет сам добавляет нужные префиксы. Внутриблочные условия полей через `contentColumn()`.
- **Artisan-команда `make:content-block`** для генерации статических и динамических (`--dynamic`) блоков.
- **Конфигурация** (`config/content-blocks.php`, публикуется тегом `content-blocks-config`): подмена модели, выбор ресурса MoonShine, типы владельцев для селектора `blockable_types`.
- **Точки расширения:** кастомная модель `ContentBlock`, ребинд `BlockFieldsBuilderInterface`, собственный админ-ресурс, реакция на осиротевшие строки через слушатель `UnknownBlockTypeEncountered`.

### Требования

- PHP >= 8.3
- Laravel ^12
- MoonShine ^4.15
- ewk/moonshine-resource-kit ^0.1
